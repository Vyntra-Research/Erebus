# Review usage

The Usage page reads local Codex session history and summarizes processed tokens, cache savings, models, and API-equivalent cost. Subscription billing and Codex credits are separate from this estimate.

Use **Past 24h** for hourly data. The **7 days**, **30 days**, and **90 days** views use daily totals. Switch between cost and tokens, then refresh to rescan the connected Erebus environment.

Account quota is shown separately in **Settings > Providers > Codex**. Quota controls account routing; the Usage page describes completed session history.
