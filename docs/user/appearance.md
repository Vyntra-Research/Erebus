# Appearance and wallpapers

Open **Settings → Appearance** to choose a theme, tune contrast and glass opacity, or add a wallpaper.

Wallpaper images stay on the current device. Erebus does not add them to thread sync or the project workspace. PNG, JPEG, WebP, and AVIF files up to 32 MB are supported.

The wallpaper effect can be left off or set to **Dither** or **Dot screen**. **Bottom wallpaper blur** adds a progressive blur near the lower edge. Glass opacity still controls the interface surfaces drawn over the image.
