# Security policy

Please report security flaws through [GitHub private vulnerability reporting](https://github.com/Vyntra-Research/Erebus/security/advisories/new).

Include the affected version, operating system, impact, reproduction steps, and the smallest proof needed to confirm the flaw. Do not open a public issue for an undisclosed vulnerability.

This repository does not promise a bug bounty or payment. Vyntra Research will confirm receipt and coordinate disclosure when the report is valid.
